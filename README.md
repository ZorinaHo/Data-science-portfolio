## Publish with GitHub Pages

1. Create a **public** GitHub repository named `data-science-portfolio` and initialize it with a README (or upload this included README).
2. Upload **the contents of this folder** to the repository root (`index.md`, `_config.yml`, `README.md`, `images/`). Do not add an extra nested `data-science-portfolio/` directory.
3. In `index.md` and `README.md`, replace every `YOUR_GITHUB_USERNAME` with your actual GitHub username. Make sure the project repository `data-science-project` is already public.
4. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**. Click **Save**.
5. Open the published URL from Pages settings and confirm both plots and the project link work.
6. Ask a classmate for feedback on the research question, finding, and limitation; make one improvement and commit with a descriptive message, e.g. `Clarify model limitations based on peer feedback`.
